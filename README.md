# QR Air

화면에 빠르게 바뀌는 QR 코드를 표시하고, 다른 기기의 카메라로 파일을 직접 받는 웹앱입니다. 파일은 서버에 업로드되지 않습니다.

## 실행

```bash
npm install
npm run dev
```

PC에서는 표시된 로컬 주소로 접속할 수 있습니다. iPhone 카메라를 사용하려면 브라우저의 보안 정책상 **HTTPS로 배포된 주소**가 필요합니다. 한 번 방문해 앱 리소스를 캐시하면 이후 전송 과정 자체에는 네트워크가 필요하지 않습니다.

## 현재 프로토콜

- 파일을 520바이트씩 분할
- 각 QR에 세션 ID, 순번, 전체 조각 수, 파일 정보 및 데이터를 포함
- 수신 순서와 관계없이 조각 수집
- 전체 파일의 SHA-256으로 무결성 검증
- 누락된 프레임은 송신기가 순환 반복하면서 보충
- 송신 화면에서 2~12 FPS 전송 속도 조절

현재 버전은 프로토타입으로 20MB 이하 파일을 권장합니다. 오류 정정용 Fountain Code는 아직 포함하지 않았습니다.
